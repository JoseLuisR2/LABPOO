La sincronización es crítica en este dominio porque el combustible es un recurso limitado y compartido. Sin un control adecuado, dos naves podrían intentar leer el nivel del tanque simultáneamente y extraer combustible que ya no existe, resultando en un estado inconsistente o valores negativos. La implementación resuelve este problema asegurando que solo un proceso modifique el tanque a la vez y que los consumidores esperen si el recurso está agotado.
