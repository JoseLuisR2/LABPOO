¿Qué diferencia hay entre JDK, JRE y JVM? ¿Por qué instalamos el JDK?
  El JDK es el paquete que usamos para programar porque trae el compilador, sin eso no podemos convertir el código en una aplicación. 
  El JRE es solo lo necesario para que el programa corra en una computadora. 
  La JVM es la que ejecuta el código final. Instalamos el JDK porque es el kit de construcción completo.

¿Por qué Java es considerado «write once, run anywhere»? Explica con tus
propias palabras.
  Porque el archivo generado puede utilizarse en cualquier computadora sin importar sus especificaciones.

¿Qué hace exactamente =System.out.println()=? ¿Qué clase y método estás
usando?
Sirve para mostrar un mensaje en la consola y saltar al siguiente renglón. 
Se usando la clase System, que es la que comunica el código con la computadora, y el método println, que es la acción específica de imprimir el texto que pongas entre las comillas.
